# Security Policy

If you find a vulnerability in Hex Earth, please open a
[GitHub security advisory](https://github.com/Nostromo-618/hex-earth/security/advisories/new)
instead of a public issue.

This is a client-only demo (no backend, no secrets). Still report anything that
could harm users who host a copy: dependency malware, prototype pollution in
the map pipeline, or unsafe handling of `localStorage` keys.
